How it works

  1. Connect your wallet (BNB Chain).
  2. We check on-chain whether the connected address holds an Agent ID (the on-chain name of an Agentic Wallet). Only the connected address is checked — nothing else is looked up.
  3. If you hold one, press Mint. Your wallet asks you to confirm the transaction — nothing is sent without your confirmation.
  4. One pass per address. The mint itself is free; you only pay network gas.

No account, no sign-up, no server: this page talks to BNB Chain directly from your browser. It never sees or stores any key.

AgentMint Pass is a free collectible. It promises no returns, no income and no yield.

Contract source is open and verified on BscScan once deployed. Owner powers are minimal: only the metadata base URI can be updated. There is no pause, no owner mint and no fund withdrawal — the mint is free by design.
Agent ID is claimed inside the Binance App (Wallet → Agent ID). This site is not affiliated with Binance.
